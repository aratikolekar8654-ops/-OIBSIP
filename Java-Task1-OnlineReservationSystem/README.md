# Java Development — Task 1: Online Reservation System

## 🌟 Objective
A GUI-based train reservation system where users can log in, book tickets, and cancel bookings using a PNR number.

## 🧠 Tech Stack
- Java Swing
- JDBC
- MySQL / SQLite

## ⚙️ Features Implemented
- Login form with username & password validation
- Reservation form with passenger details, train number, class, date, source, destination
- Auto-generated PNR number for each booking
- Cancellation form using PNR number
- Input validation (numeric train number, valid date format)

## 🚀 How to Run
1. Import project into Eclipse or IntelliJ.
2. Setup database using provided SQL script.
3. Run `Main.java`.
4. Login → Book Ticket → Cancel Ticket.
