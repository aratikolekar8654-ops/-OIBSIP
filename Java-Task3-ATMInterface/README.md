
# Java Development — Task 3: ATM Interface

## 🌟 Objective
A console-based simulation of an ATM machine that allows users to authenticate with a PIN and perform banking transactions.

## 🧠 Tech Stack
- Java (Console Application)
- Object-Oriented Programming (OOP)
- ArrayList for transaction history

## ⚙️ Features Implemented
- User login with ID and PIN (3 attempts max)
- Withdraw, Deposit, Transfer operations
- Transaction history stored in ArrayList
- Balance validation with "Insufficient Funds" message
- Quit option with goodbye message
- Classes: ATM, Account, Transaction, Bank, Main

## 🚀 How to Run
1. Import project into Eclipse/IntelliJ.
2. Run `Main.java`.
3. Login with sample accounts:
   - User ID: `user1`, PIN: `1234`
   - User ID: `user2`, PIN: `4321`
4. Perform transactions via menu options.
