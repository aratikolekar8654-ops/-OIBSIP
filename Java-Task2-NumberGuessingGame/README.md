# Java Development — Task 2: Number Guessing Game

## 🌟 Objective
A console-based game where the computer generates a random number and the user attempts to guess it with hints.

## 🧠 Tech Stack
- Java (Console Application)
- java.util.Random
- java.util.Scanner

## ⚙️ Features Implemented
- Random number generation (1–100)
- User input with hints ("Too High", "Too Low")
- Attempt counter with maximum 7 attempts
- "Play Again" option after each round
- Score tracking across rounds

## 🚀 How to Run
1. Open project in Eclipse/IntelliJ.
2. Run `NumberGuessingGame.java`.
3. Enter guesses until correct or attempts run out.
